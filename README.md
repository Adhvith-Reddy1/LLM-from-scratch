# LLM From Scratch

My implementations while working through *Build a Large Language Model (From Scratch)* by Sebastian Raschka.

| Notebook | Covers |
|---|---|
| [ch02_encoding.ipynb](ch02_encoding.ipynb) | Tokenization, vocabularies, byte pair encoding, sliding-window data loading, token and positional embeddings |
| [ch03_attention.ipynb](ch03_attention.ipynb) | Simplified self-attention, scaled dot-product attention, causal masking, dropout, multi-head attention |

## Setup

```bash
pip install -r requirements.txt
jupyter notebook
```

`the-verdict.txt` (Edith Wharton's short story "The Verdict", public domain) is the training text used in chapter 2.
